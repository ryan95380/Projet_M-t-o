Petite application web permettant d’afficher la météo en temps réel à partir d’une API.

Le projet utilise JavaScript pour récupérer les données météo et les afficher dynamiquement selon la ville recherchée.
L’interface est volontairement simple et responsive.

Technologies utilisées

HTML

CSS

JavaScript

API météo

👉 Projet réalisé dans un objectif d’apprentissage et de mise en pratique des appels API en JavaScript.
